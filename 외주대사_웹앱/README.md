# 외주명세서 대사 웹앱

업체별 거래명세서(PDF 스캔본)와 ERP 외주입고이력(엑셀)을 대사해, 틀린 곳을 업체·파일·페이지·행·항목까지 짚어 줍니다.

## 실행

`실행.bat`을 더블클릭합니다.

- 처음 실행할 때만 파이썬 가상환경(`.venv`)을 만들고 패키지를 설치합니다(몇 분 걸림). 파이썬이 없으면 winget으로 설치를 시도합니다.
- 빈 포트(8517부터)를 골라 앱을 띄우고 브라우저를 엽니다. 다른 Streamlit 앱이 켜져 있어도 충돌하지 않습니다.
- 다 쓴 뒤에는 검은 창을 닫으면 앱이 꺼집니다.

## AI 판독 설정

`.env` 파일(첫 실행 때 자동 생성)에 Claude API 키를 넣습니다.

```
ANTHROPIC_API_KEY=sk-ant-...
CLAUDE_MODEL=claude-opus-5-5
CLAUDE_EFFORT=high
```

키가 없으면 화면에서 키를 입력하거나, **판독 파일 불러오기**로 예전에 내려받은 판독 결과 JSON을 쓸 수 있습니다.
명세서 이미지는 판독할 때 Claude API로 전송됩니다(사내 보안 확인 필요 — 계획서 8장).

## 사용 순서

1. 사이드바에 ERP 엑셀과 명세서 PDF 여러 개를 올립니다. 업체는 파일명으로 자동 인식하며, 못 찾으면 드롭다운으로 지정합니다.
2. **[판독 시작]** → 페이지마다 AI가 표를 읽고, 끝나면 대사가 자동으로 실행됩니다.
3. **업체별 요약** 탭: 합계·차이·판정, 엑셀 내려받기(요약·불일치 리포트·판독 원본 3개 시트), 업체 회신 문구 초안
4. **불일치 리포트** 탭: 행을 클릭하면 오른쪽에 해당 PDF 페이지가 열리고 문제 행에 빨간 띠가 표시됩니다.
5. **판독 결과 확인** 탭: 검산 실패(⚠️/노란색) 행을 PDF와 비교해 고치고 **[수정 반영 후 다시 대사]**. 수정본은 JSON으로 내려받아 다음에 다시 불러올 수 있습니다.

판독 결과와 리포트는 PC나 서버에 저장하지 않습니다. 창을 닫으면 사라지므로 필요한 것은 내려받으세요.

## 업체 추가

`config/vendors.yaml`에 업체코드·상호 별칭·파일명 키워드·양식 특징을 한 덩어리 추가하면 됩니다(코드 수정 불필요).

## 테스트

```
.venv\Scripts\python tests\run_sample_test.py       # 9월 정답지로 대사 규칙 검증 (API 불필요)
.venv\Scripts\python tests\run_ai_reading_test.py   # AI 판독 정확도 검증 (API 키 필요, 21페이지 호출)
```

`tests/sample_202609/판독정답_202609.json`은 9월 명세서 21페이지 134행을 사람이 직접 옮겨 적은 판독 정답입니다.
앱에서 **판독 파일 불러오기**로 올리면 API 없이 9월 샘플로 전체 화면을 확인할 수 있습니다.

## 구성

```
실행.bat / launcher.py     실행 (최초 1회 설치 → 빈 포트로 streamlit 실행 → 브라우저 열기)
app.py                     화면
core/erp_loader.py         ERP 엑셀 읽기·정규화
core/pdf_reader.py         PDF→이미지, AI 판독, JSON→표, 표 괘선으로 행 위치 찾기
core/validator.py          수량×단가, 명세서 인쇄 합계 검산
core/matcher.py            1·2차 매칭, 유형 판정, 묶음
core/report.py             요약, 엑셀 내보내기, 회신 문구
core/pipeline.py           위 단계를 순서대로 묶음
config/vendors.yaml        업체 마스터
```
