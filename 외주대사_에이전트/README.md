# 외주 마감 대사 에이전트 (Claude Code용)

외주거래명세서 스캔본(PDF)과 ERP 외주입고이력(엑셀)을 업체별로 비교해,
차이가 있는 건을 **명세서 파일명 · 페이지 · No** 로 짚어주는 에이전트입니다.

## 처음 한 번만
1. Python 3.10 이상 설치
2. 이 폴더에서 `pip install -r requirements.txt`
3. Claude Code 설치 후, 이 폴더에서 `claude` 실행 (CLAUDE.md를 자동으로 읽습니다)

## 매월 마감 때
1. `input/2026-10/거래명세서_스캔/` 에 업체 스캔 PDF를 넣습니다. 파일명에 업체 약칭이 들어가게 해 주세요 (예: `대성정밀_거래명세서_202610.pdf`).
2. `input/2026-10/ERP_입고이력/` 에 ERP에서 내려받은 입고이력 엑셀을 넣습니다.
3. Claude Code에서 `/reconcile 2026-10` 또는 "10월 외주 대사해줘" 라고 입력합니다.
4. 결과: `output/2026-10/외주대사결과_202610.xlsx`
   - **요약**: 업체별 금액 차이·건수·판정
   - **상이내역**: 차이 1건 = 1행, 명세서 페이지·No 순 정렬, 담당자 확인결과 기재칸 포함
   - **매칭내역**: 명세서 행 ↔ ERP 입고번호 짝 전체 (감사 추적용)
   - **명세서판독**: 에이전트가 스캔본에서 읽어낸 원본 값

## 우리 회사 ERP에 맞추기
ERP 엑셀의 컬럼명이 다르면 `config/대사기준.json` 의 `erp_columns` 오른쪽 값을 실제 헤더명으로 바꾸면 됩니다.
업체가 늘면 `config/업체마스터.csv` 에 한 줄 추가합니다.

## 가상 데이터로 먼저 시험해 보기
`input/2026-09/` 에 가상 업체 7곳의 9월분이 들어 있습니다.
Claude Code에서 **"테스트 모드로 2026-09 대사 돌려줘"** 라고 하면, 대사를 끝낸 뒤 `tests/정답_의도된차이.md` 와 비교해 채점까지 합니다.

| 업체 | 심어둔 차이 |
|---|---|
| (주)대성정밀 | 수량 오타 1건, 단가인상 미반영 4건 |
| 한울도금(주) | 없음 (대조군) |
| 세진열처리 | ERP 입고누락 1건, ERP 중복입고 1건 |
| (주)우림도장 | 품번 오기 1건, 입고일자 상이 1건, 수기정정 1건 |
| 동아사출산업 | ERP에만 있는 전월분 1건, 세액 끝전차이 다수 |
| (주)성원금속 | **양식 다름**: 가로 거래명세표, 순번·발주번호·라인세액 칸 없음, 월/일 분리 → 수량 상이 1건, 입고일자 상이 1건 |
| 한성유압정공(주) | **양식 다름**: 납품 1건=1장(9장), 날짜는 머리글에만, 반품 △ 표기 → 반품 ERP 미처리 1건, ERP 분할입고(25+15) 1건 |

스크립트만 따로 확인하려면 (판독 단계 생략):
```
mkdir work\2026-09\추출            (Mac: mkdir -p work/2026-09/추출)
copy tests\기대_추출결과\* work\2026-09\추출\
python scripts/validate_extraction.py --month 2026-09
python scripts/reconcile.py --month 2026-09
```
