# 고객사별 매출 집계 대시보드 개발설계서

작성일: 2026-10-16

## 1. 개요

월별 출하실적 엑셀 3개와 분기목표·지난분기 집계표를 올리면 고객사별 분기 달성률, Top 3, 월별 추이를 한 화면에 보여주고 지난 분기와 같은 양식의 엑셀로 저장하는 Python + Streamlit 앱을 만든다.

| 항목 | 내용 |
| --- | --- |
| 사용자 | 한빛정밀 영업팀 대리 1명(혼자 사용) |
| 해결할 문제 | 엑셀 3개를 손으로 열어 합산하느라 시간이 걸리고 계산 실수가 잦음 |
| 앱 형태 | Python + Streamlit, 실행.bat 더블클릭으로 실행(엑셀 읽기·내보내기가 있으므로) |
| 저장 | 하지 않음. 올린 파일은 화면을 닫으면 사라짐 |
| 범위 밖 | 품목별 분석, PDF 보고서, 여러 분기 누적 관리(첫 버전 이후 검토) |

## 2. 확정 요구사항

추가 질문 13개는 모두 추천안으로 확정했다. 지난 분기 집계 방식을 그대로 따르는 것이 기본 원칙이다.

| 번호 | 질문 | 확정 내용 |
| --- | --- | --- |
| 1 | 반품 반영 월 | 반품이 기록된 달에서 차감(9월 반품은 9월 매출에서 뺌) |
| 1-1 | 반품 비고 날짜 불일치 | 화면에 경고로 표시 |
| 2 | 판정 기준 | 달성률 90% 미만 = 미달(빨강), 전월 대비 −20% 이하 = 주의(노랑), 정확히 90.0%는 정상 |
| 3 | 달성률 자릿수 | 소수점 1자리 |
| 4 | 전월 대비 | 분기 마지막 달 vs 직전 달, 직전 달 0원이면 '비교불가' |
| 5 | Top 3 기준 | 분기 매출액 순 |
| 6 | Top 3 강조 | 카드 맨 앞 배치 + 1·2·3위 순위 뱃지 |
| 7 | 지난 분기 비교 | 카드 안에 '2분기 대비 ±○%' 한 줄 |
| 8 | 파일 넣는 방식 | 화면에서 파일을 끌어다 올리기 |
| 9 | 다음 분기 양식 | 열 이름·순서와 파일명 규칙이 지금과 같다고 가정 |
| 10 | 내보내기 | 지난분기 집계표와 같은 양식의 엑셀 |
| 11 | 추가 분석 | 없음(첫 버전은 요구사항 범위만) |
| 12 | 금액 단위 | 원 그대로, 쉼표 구분 |
| 13 | PC 환경 | Windows, Python 설치 가능 |

## 3. 입력 데이터 명세

입력은 엑셀 3종 5개 파일이며, 앱은 아래 열 이름으로 데이터를 찾는다.

| 파일 | 개수 | 시트 | 읽는 위치 | 사용하는 열 |
| --- | --- | --- | --- | --- |
| 출하실적_YYYY-MM.xlsx | 분기당 3개 | 출하실적 | 1행이 열 이름 | 출하일, 출하번호, 고객사, 품번, 금액, 비고 |
| 고객사_분기목표.xlsx | 1개 | 분기목표 | 1행이 열 이름 | 고객사, 분기, 목표금액 |
| 지난분기_매출집계표.xlsx | 1개 | 첫 시트 | '고객사'가 적힌 행(4행)부터 표 | 고객사, 분기 합계 |

읽기 규칙은 다음과 같다.

1. 출하실적은 파일명이 아니라 출하일로 월을 정한다. 파일명과 출하일의 월이 다르면 경고한다.
2. 세 파일의 출하일이 같은 분기의 연속된 3개월이 아니면 경고하고 집계를 멈춘다.
3. 분기목표는 출하일로 정한 분기(예: 2026년 3분기)와 '분기' 열이 같은 행만 쓴다.
4. 지난분기 집계표는 '고객사' 열의 값이 '합계'나 '분기 합계 상위 3'인 행과 그 아래 설명 행을 건너뛴다.
5. 금액은 파일에 적힌 '금액' 열을 그대로 합산하고, 수량 × 단가와 다르면 경고만 한다.

## 4. 계산 규칙

모든 계산은 원 단위 정수로 하고, 비율은 마지막에 한 번만 소수점 1자리로 반올림한다.

| 항목 | 계산식 | 비고 |
| --- | --- | --- |
| 월 매출 | 해당 월 출하 행의 금액 합계 | 반품(음수 금액)도 기록된 달에 그대로 포함 |
| 분기 합계 | 3개월 월 매출의 합 | 출하가 없는 달은 0원 |
| 달성률 | 분기 합계 ÷ 분기 목표 × 100 | 판정은 반올림 전 값으로 비교 |
| 전월 대비 | (마지막 달 − 직전 달) ÷ 직전 달 × 100 | 직전 달 0원이면 '비교불가' |
| 2분기 대비 | (3분기 합계 − 2분기 합계) ÷ 2분기 합계 × 100 | 지난분기 집계표에 없는 고객사는 '신규' |
| Top 3 | 분기 합계 내림차순 상위 3곳 | 금액이 같으면 달성률이 높은 쪽 |
| 전체 합계 | 고객사 전체의 월별·분기·목표 합계와 그 달성률 | 카드 위 요약 숫자로 표시 |

판정은 다음 순서로 하나만 정한다.

1. 달성률이 90% 미만이면 미달(빨강).
2. 아니면 전월 대비가 −20% 이하일 때 주의(노랑).
3. 둘 다 아니면 정상. 전월 대비가 '비교불가'이면 달성률로만 판정한다.

판정에는 반올림 전 값을 쓴다. 그래서 89.96%는 화면에 90.0%로 보여도 미달이며, 이런 경우 카드에 실제 값을 툴팁으로 함께 보여준다.

## 5. 화면 설계

한 페이지를 위에서 아래로 읽는 구성이며, 왼쪽 사이드바에서 파일을 올리면 본문이 채워진다.

1. 사이드바(파일 올리기)
    - 출하실적 3개, 분기목표 1개, 지난분기 집계표 1개를 각각 올리는 칸 3개.
    - 칸마다 '올림 완료 / 필요' 상태와 인식된 월·분기를 표시.
    - 하단에 '엑셀로 저장' 버튼.
2. 상단 요약 줄
    - 집계 분기(예: 2026년 3분기), 전체 분기 매출, 전체 목표, 전체 달성률, 2분기 대비 증감.
3. 경고 영역(경고가 있을 때만)
    - 노란 상자에 7장의 경고 문구를 한 줄씩 나열.
4. 고객사 카드
    - Top 3를 맨 앞에 순서대로 놓고 1·2·3위 뱃지를 단다. 나머지는 매출액 순.
    - 카드 내용: 고객사명, 분기 매출, 목표, 달성률(진행 막대), 전월 대비, 2분기 대비, 판정 색.
    - 판정 색은 카드 왼쪽 테두리와 판정 글자에 쓴다(빨강 미달, 노랑 주의, 회색 정상).
5. 월별 통계 표
    - 지난분기 집계표와 같은 열: 고객사, 7월, 8월, 9월, 분기 합계, 분기 목표, 달성률, 전월 대비, 판정. 맨 아래 합계 행.
6. 그래프 2개
    - 고객사별 월 매출 추이: 고객사마다 선 하나, x축 7·8·9월.
    - 고객사별 목표 대비 실적: 고객사마다 실적 막대와 목표 표시선, 달성률 순 정렬.

금액은 모두 원 단위 쉼표 표기(예: 17,957,000원)로 보여준다.

## 6. 내보내기

'엑셀로 저장' 버튼은 지난분기_매출집계표.xlsx와 같은 배치의 파일을 내려받게 한다. 파일명은 `2026년_3분기_고객사별_매출집계표.xlsx` 형식이다.

| 행 | 내용 |
| --- | --- |
| 1 | 제목: 2026년 3분기 고객사별 매출 집계표 |
| 2 | 작성 정보: 작성일 · 출하실적 7~9월 기준 (단위: 원) |
| 3 | 빈 행 |
| 4 | 열 이름: 고객사, 7월, 8월, 9월, 분기 합계, 분기 목표, 달성률, 전월 대비, 판정 |
| 5~10 | 고객사별 행(고객사명 가나다순, 지난 분기와 같은 순서) |
| 11 | 합계 행 |
| 12 | 분기 합계 상위 3: 1위 → 2위 → 3위 |
| 13 | 판정 기준 설명 문구 |
| 14~ | 경고가 있으면 '경고' 제목 아래 한 줄씩 |

서식은 금액 열에 천 단위 쉼표, 달성률·전월 대비는 백분율 소수점 1자리, 판정 칸은 미달 빨강·주의 노랑 배경으로 한다. 달성률 등은 계산된 값을 숫자로 넣고 엑셀 수식은 쓰지 않는다. 지난 분기 파일과 같은 방식이며, 열어 볼 때 값이 바로 보이도록 하기 위해서다.

## 7. 예외 처리와 경고

경고는 집계를 막지 않고 화면과 내보낸 엑셀에 함께 남긴다. '멈춤'으로 표시한 경우만 집계를 하지 않고 이유를 보여준다.

| 상황 | 처리 | 이번 데이터 해당 여부 |
| --- | --- | --- |
| 필수 열(고객사·금액·출하일)이 없음 | 멈춤, 어느 파일의 어느 열인지 표시 | 없음 |
| 출하실적 3개가 같은 분기 연속 3개월이 아님 | 멈춤 | 없음 |
| 반품(음수 금액) 행이 있음 | 기록된 달에 차감, 경고에 건별 표시 | 9월 다온기계 −195,000원 |
| 반품 비고의 원출하일에 같은 고객사·품번 출하가 없음 | 경고 | 비고 '8/28 출하분'이나 8월 다온기계 PN-1006 출하는 8/6뿐 |
| 어떤 달에 출하가 없는 고객사 | 그 달 0원, 경고에 표시 | 8월 마루밸브 |
| 직전 달 0원이라 전월 대비 계산 불가 | '비교불가' 표시, 달성률로만 판정 | 마루밸브 |
| 출하실적에는 있는데 분기목표에 없는 고객사 | 목표 '없음', 달성률·판정 비움, 경고 | 없음 |
| 분기목표에는 있는데 출하가 0건인 고객사 | 분기 0원으로 카드 표시 | 없음 |
| 금액이 수량 × 단가와 다름 | 파일의 금액으로 집계, 경고 | 없음 |
| 출하번호 중복 | 두 행 모두 집계, 경고 | 없음 |
| 고객사명 앞뒤 공백 | 공백을 지워 같은 고객사로 처리 | 없음 |

## 8. 기술 구성과 실행 방법

Python 3.11 이상, Streamlit, pandas, openpyxl, plotly 4개 라이브러리만 쓴다. 인터넷 연결은 처음 설치할 때만 필요하다.

| 파일 | 역할 |
| --- | --- |
| app.py | 화면 구성(사이드바, 요약, 카드, 표, 그래프, 저장 버튼) |
| calc.py | 파일 읽기, 검증, 집계·판정 계산(화면과 분리해 검산하기 쉽게) |
| export.py | 집계표 양식 엑셀 만들기 |
| requirements.txt | 필요한 라이브러리 목록 |
| 실행.bat | 처음엔 라이브러리 설치, 이후엔 앱 실행과 브라우저 자동 열기 |
| 사용법.txt | 실행 방법과 파일 올리는 순서 한 페이지 |

실행 순서는 다음과 같다.

1. 처음 한 번: Python을 설치하고(설치 화면에서 'Add Python to PATH' 체크) 폴더를 원하는 위치에 둔다.
2. 실행.bat을 더블클릭한다. 첫 실행은 라이브러리 설치로 1~2분 걸린다.
3. 브라우저에 앱이 열리면 사이드바에 파일 5개를 끌어다 놓는다.
4. 사용을 마치면 검은 실행 창을 닫는다.

## 10. 개발 순서와 테스트

계산을 먼저 만들어 9장 값과 맞춘 뒤 화면과 내보내기를 붙인다. 숫자가 맞는지 확인한 다음에 보기 좋게 만드는 순서다.

1. calc.py: 파일 읽기와 검증, 집계·판정 계산.
2. calc.py 검산: 첨부 파일로 돌려 9장 표와 비교.
3. app.py: 사이드바, 요약 줄, 경고, 카드, 표.
4. app.py: 그래프 2개.
5. export.py: 집계표 엑셀 저장.
6. 실행.bat과 사용법.txt, 회사 PC에서 처음부터 설치해 보기.
