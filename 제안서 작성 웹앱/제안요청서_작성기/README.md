# 제안요청서 자동 작성기 — 사용법

## 처음 한 번만
1. Python 3.10 이상 설치 (https://www.python.org/downloads/)
   설치 첫 화면에서 **"Add Python to PATH"** 를 꼭 체크하세요.

## 실행
1. `실행.bat` 을 더블클릭합니다.
   (처음에는 필요한 프로그램을 설치하느라 1~2분 걸릴 수 있습니다.)
2. 브라우저가 자동으로 열립니다. 안 열리면 주소창에 `http://localhost:8501` 입력.
3. 다 쓰면 검은 창을 닫습니다.

## 사용 순서
1. **① 파일 올리기** — 구매요청서.xlsx 를 끌어다 놓습니다.
   양식이나 협력사목록이 바뀌었으면 "양식·협력사목록 바꾸기"를 펼쳐 새 파일을 올립니다.
   (기본 파일을 아예 바꾸려면 `data` 폴더의 파일을 같은 이름으로 교체하세요.)
2. **② 작성 설정** — 요청일(기본: 오늘)과 견적 회신 기한(요청일 + 3영업일 17:00)을 확인합니다.
   공휴일이 끼어 있으면 회신 기한 날짜를 직접 고쳐 주세요.
3. **③ 대상 확인** — 상태가 `요청서 발송 전`인 건만 품목군으로 협력사와 짝지어 나옵니다.
   이번에 보내지 않을 건은 "포함" 체크를 풉니다. 비고는 화면에만 보이고 요청서에는 들어가지 않습니다.
4. **④ 제안요청서 만들기** 버튼을 누릅니다.
5. **⑤ 결과 목록** — [전체 ZIP 다운로드] 또는 각 행의 [다운로드]로 받습니다.

## 알아 둘 점
- 요청번호: `RFQ-2610-001-서진금속` / 파일명: `RFQ-2610-001_서진금속_SUS304환봉.docx`
- 한 협력사가 여러 품목군에 있으면 구매요청 건별로 따로 만들어집니다.
- 만든 파일은 저장되지 않습니다. 앱을 닫기 전에 꼭 내려받으세요.
- 구매요청서의 "상태" 값은 바꾸지 않습니다. 발송 후 엑셀에서 직접 고쳐 주세요.
