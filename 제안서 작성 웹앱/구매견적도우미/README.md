# 구매 견적 도우미 — 사용법

메뉴가 두 개 있습니다.
- 📝 **제안요청서 작성**: 구매요청서 엑셀 → 협력사별 제안요청서(.docx). AI를 쓰지 않습니다.
- 📊 **견적 분석·협상전략**: 협력사에서 받은 견적서 → AI가 읽고, 프로그램이 비교 계산하고, AI가 협상전략을 제안합니다.

## 처음 한 번만
1. Python 3.10 이상 설치 (https://www.python.org/downloads/)
   설치 첫 화면에서 **"Add Python to PATH"** 를 꼭 체크하세요.
2. (견적 분석 메뉴를 쓸 때만) API 키 설정 — 키는 이 폴더의 `.env` 파일에 저장됩니다.
   - 방법 1 (화면): 앱 왼쪽 사이드바 **AI 설정**에 키를 붙여 넣고 [저장]. 저장과 동시에 연결을 확인합니다.
   - 방법 2 (파일): `.env.example`을 복사해 `.env`로 저장하고 `ANTHROPIC_API_KEY=` 뒤에 키를 넣습니다.
   - 모델을 바꾸려면 AI 설정의 "모델" 칸(또는 `.env`의 `CLAUDE_MODEL=`)을 고칩니다. (기본: claude-sonnet-5-5)
   - (키 발급: https://console.anthropic.com)

## 실행
1. `실행.bat` 을 더블클릭합니다. (처음에는 필요한 프로그램 설치로 1~2분 걸릴 수 있습니다)
2. 브라우저가 자동으로 열립니다. 안 열리면 주소창에 `http://localhost:8611` 입력.
3. 다 쓰면 검은 창을 닫습니다.

## 📊 견적 분석·협상전략
1. **① 견적서 올리기** — 받은 견적서를 모두 올립니다. (xlsx, pdf, png, jpg / hwp·doc은 PDF로 저장 후)
2. **② 비교 기준 (선택)** — 비워 두면 **견적서에서 읽은 품목과 견적수량**을 기준으로 비교합니다.
   - 희망 납기를 지정하면 납기 충족 여부(충족 / n일 지연)도 판정합니다.
   - 비교 기준 수량을 직접 넣을 수 있습니다. (MOQ 때문에 더 사야 하는 수량·실질단가 계산에 쓰입니다)
   - 구매요청서를 연결하면 그 품목·수량·희망 납기를 참고값으로 씁니다. (선택)
3. **③ 분석 설정** — 발주 예정일, 협상 우선순위(가격/납기/균형), 메모.
4. **④ [분석]** — 견적서 1장당 AI 1회 + 협상전략 1회 호출합니다.
5. **⑤ 추출 결과** — AI가 읽은 값을 확인하고 틀린 곳을 고친 뒤 **[다시 분석]** (견적서를 다시 읽지 않고 계산·전략만 새로 만듭니다).
6. **⑥ 비교표 · ⑦ 협상전략 · ⑧ 다운로드** — 견적비교표.xlsx, 협상전략.docx.

알아 둘 점
- 금액·날짜 계산은 프로그램이 하고, AI는 견적서 읽기와 전략 작성만 합니다.
- 메일 초안에 다른 협력사 이름·금액이 들어가면 화면에 빨간 경고가 뜹니다. 보내기 전에 꼭 확인하세요.
- **견적서 내용은 분석을 위해 Anthropic API로 전송됩니다.** 사내 정보보안 규정상 외부 AI 사용이 허용되는지 먼저 확인하세요.
- API 사용료는 호출량에 따라 나옵니다. 사용량은 Anthropic Console에서 확인합니다.
- 앱은 아무것도 저장하지 않습니다. 내려받은 파일만 남습니다.
- 폴더를 다른 사람에게 줄 때는 `.env` 파일을 빼고 주세요.
- `샘플_견적서` 폴더에 연습용 견적서 3장이 있습니다.

## 📝 제안요청서 작성
v1과 같습니다. 구매요청서를 올리고 대상 확인 → [제안요청서 만들기] → 개별/ZIP 다운로드.
여기서 올린 구매요청서는 견적 분석 메뉴에서도 다시 올리지 않고 쓸 수 있습니다(앱을 닫으면 사라짐).
