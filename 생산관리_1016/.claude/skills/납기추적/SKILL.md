# 납기 지연·위험 추적

CLAUDE.md의 납기 판단 기준(지연 D > +3, 위험 -3 ≤ D ≤ +3)과 카톡 우선 규칙을 따른다.

## 절차
1. `수주대장.xlsx`의 `수주대장`, `변경이력` 시트를 읽는다.
2. 상태를 보정한다. 단톡방과 `메일함/`의 출하팀 보고에 출하 기록이 있으면 출하완료로 보고, 원본 상태와 다르면 "상태 불일치" 열에 적는다.
3. 기준일로 각 미출하 건의 D값을 계산하고 지연, 위험, 정상으로 나눈다.
4. `품목마스터.csv`의 담당라인을 붙인다. 최근 생산일보에서 해당 품번의 최근 실적을 붙여 잔량을 추정할 수 있으면 추정하고, 추정할 수 없으면 `[확인]`을 적는다.
5. 카톡, 메일, 회의록에서 그 수주번호가 언급된 최근 내용을 "최근 동향"에 적는다(날짜 포함).

## 결과물
- `납기현황/납기현황_MMDD.xlsx`(기준일 기준)
  - 시트 `요약`: 지연, 위험, 정상, 출하완료 건수, 라인별 지연·위험 건수
  - 시트 `지연·위험`: 구분, 수주번호, 고객사, 품번, 품명, 수량, 납기일, D값, 담당라인, 진행상태(원본), 상태 불일치, 최근 동향, 확인 필요
  - 지연은 빨강, 위험은 주황 배경으로 표시한다.
- 답변에는 지연 건과 위험 건을 짧은 표로 보여주고, 라인 반장에게 확인할 항목을 `[확인]`으로 모아준다.
- 특정 수주번호를 물으면 파일 없이 그 건의 상태, D값, 최근 동향만 답한다.
