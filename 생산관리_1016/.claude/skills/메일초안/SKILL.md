# 고객 메일 초안 작성

## 절차
1. 원본 메일(`메일함/*.eml`, UTF-8)을 읽고 고객의 요청사항, 요청 기한, 관련 수주번호를 뽑는다.
2. `고객사_담당자.xlsx`에서 수신자 이름, 직급, 이메일과 비고(예: "납기 변경 1순위 우선 검토")를 확인한다.
3. 수주대장, 카톡, 회의록에서 그 수주의 현재 상태와 내부 결정사항을 확인한다. 카톡 내용을 우선한다.
4. 초안을 쓴다.
   - 발신자는 생산관리팀 박서준 대리로 하고, 사용자가 다른 사람을 지정하면 그 사람으로 쓴다. 정중한 비즈니스 존댓말로, 결론을 먼저 쓴다.
   - **팀장 승인 전에는 납기나 수량을 확정해서 약속하지 않는다.** 내부 결정이 확인되지 않은 날짜와 수량은 `[확인] 팀장 승인 필요`로 표시한다(납기 변경 절차: 반장 확인 → 팀장 승인 → 담당자 회신).
   - 클레임 회신은 품질팀(한지연)이 확인한 원인과 대책만 쓰고, 확인되지 않은 원인은 `[확인]`으로 둔다.
   - 단가와 다른 고객사 정보는 넣지 않는다.

## 결과물
- `메일초안/MMDD_고객사_수주번호_주제.txt`
  - 첫머리: 받는 사람, 참조(필요할 때), 제목
  - 본문
  - 마지막에 `---` 아래 내부 메모: 근거 자료(파일명과 날짜), `[확인]` 목록, 회신 기한
- 답변에는 초안 본문과 `[확인]` 목록을 보여준다. 발송은 사용자가 직접 한다.
