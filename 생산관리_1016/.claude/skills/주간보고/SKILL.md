# 주간보고 작성

CLAUDE.md의 공통 규칙과 납기 판단 기준을 따른다.

## 1. 대상 주와 자료 정하기
- 사용자가 기간을 주지 않으면 기준일이 속한 주의 월~금을 대상으로 한다.
- `보고서/`에서 가장 최근 주간보고 docx를 양식으로 쓴다. 양식 파일은 수정하지 않고 복사해서 새 파일을 만든다.
- 해당 기간의 생산일보 4개 라인 파일, 단톡방, 메일함, 회의록, 품질 자료를 모은다. 빠진 라인이 있으면 그 라인 칸에 `[확인] 생산일보 없음`을 적는다.

## 2. 양식 항목 (순서와 표 구성을 그대로 유지)
머리말: 작성(생산관리팀 박서준 대리), 수신(김도현 팀장), 작성일, 기준(수주대장 기준 시각, 생산일보 기간)

1. **납기 현황**: 요약 한 줄(지연 N건 · 위험 N건 · 정상 N건 · 출하완료 N건, 총 N건)
   - 지연 건 표: 고객사, 수주번호, 품목, 수량, 납기, 경과일, 조치·예정
   - 위험 건 표: 고객사, 수주번호, 품목, 수량, 납기, 진행상태, 비고
   - 양식의 "임박(3일 이내)" 제목은 "위험(납기 D-3~D+3)"으로 바꾸고, 표 구조는 그대로 둔다.
   - 조치·예정과 비고는 카톡, 메일, 회의록 결정사항에서 가져온다. 근거가 없으면 `[확인]`을 적는다.
2. **생산 실적**: 라인별 계획, 실적, 달성률, 불량률, 미달 일(일 달성률 90% 미만인 날짜와 그날 달성률)
   - 달성률 = 실적 / 계획, 불량률 = 불량 / 실적이다. 소수점 첫째 자리까지 쓴다.
   - 합계 줄과 미달 원인 줄을 적는다. 원인은 카톡이나 현장메모에서 찾고, 못 찾으면 `[확인]`을 적는다.
3. **품질(고객 클레임)**: 접수번호, 접수일, 고객사, 건, 상태, 회신 기한. `품질/클레임_추적표.xlsx`가 있으면 그 내용을 우선한다.
4. **다음 주 납기 예정**: 다음 주 월~금(주말 납기 포함) 납기 건. 납기, 수주번호, 고객사, 품목, 수량, 진행상태
5. **특이사항·요청**: 고객 문의, 클레임, 설비 일정(생산계획의 특이일정 시트), 회의 결정사항 중 기한이 다가온 것

## 3. 검산 후 저장
- 납기 현황 건수 합계가 수주대장 전체 건수와 같은지, 라인별 합계가 일보 합계와 같은지 확인한다.
- 저장 위치는 `보고서/주간보고_{M}월{W}주_MMDD-MMDD.docx`이다.
- 사용자에게 요약 수치 3~4줄, `[확인]` 목록, 파일 경로를 알려준다. 메일 발송은 사용자가 직접 한다.
