아래 명세를 따르는 `.skills/tdd-green/SKILL.md` 파일을 생성해 주세요.

## Skill 명세

**이름**: tdd-green  
**목적**: 실패하는 테스트를 통과시키는 최소한의 구현 코드를 작성합니다.

### 트리거 조건
- "테스트 통과시켜줘", "Green 단계 시작"
- "tdd-green Skill 사용해서"
- "구현 코드 작성해줘" (테스트 파일이 존재하는 컨텍스트에서)
- "FAILED 테스트를 통과시켜줘"

### 입력
- `test_<모듈명>.py`: 실패하는 테스트 파일 (필수)
- 해당 테스트의 TASK 설명 (선택)

### 출력
- `<모듈명>.py`: 테스트를 통과하는 구현 파일

### 구현 원칙 (핵심 규칙)
1. **테스트를 통과하는 가장 단순한 코드만 작성합니다.**
2. **클래스, 상속, 디자인 패턴을 미리 도입하지 않습니다.**
3. **함수 하나는 10줄을 넘기지 않습니다.**
4. **테스트에 없는 기능을 미리 구현하지 않습니다.**
5. 구현 완료 후 `pytest test_*.py -v`를 실행하여 모두 PASSED를 확인합니다.

### 제약사항
- **`test_*.py` 파일을 절대 수정하지 않습니다.**
- PASSED 상태가 되지 않으면 오류 메시지를 분석하여 재시도합니다.
- 전역 변수를 사용하지 않습니다.
- 외부 라이브러리를 새로 추가하지 않습니다 (표준 라이브러리만 사용).

### SKILL.md 완성 후 수행할 것
1. `.skills/tdd-green/SKILL.md` 경로에 파일 생성
2. 즉시 테스트: `tdd-red`로 생성한 `test_calculator.py`의 테스트 통과 구현
3. `pytest test_calculator.py -v` → 모두 PASSED 확인
4. 코드가 "최소한"인지 직접 리뷰 (불필요한 추상화 제거)
