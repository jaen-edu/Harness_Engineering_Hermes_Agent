## Skill 명세

**이름**: prd-writer  
**목적**: 사용자가 제공한 프로젝트 정보를 바탕으로 PRD.md를 구조화된 형식으로 작성합니다.

### 트리거 조건 (중요: 아래 패턴 중 하나가 감지될 때만 동작)
- "PRD 작성해줘", "PRD 만들어줘"
- "요구사항 문서 작성"
- "prd-writer Skill 사용해서"

### 입력
- 프로젝트 이름 (없으면 사용자에게 질문)
- 핵심 기능 요약 (없으면 사용자에게 질문)
- 대상 사용자 (없으면 "일반 사용자"로 기본값)

### 출력
- `PRD.md` 파일 (프로젝트 루트에 생성)
- 반드시 포함할 섹션: 배경, 목표, 사용자 스토리(최소 3개), 기능 목록, 비기능 요구사항, 범위 밖, 성공 지표

### 제약사항
- "빠르게", "쉽게", "편리하게" 같은 모호한 표현을 사용하지 않습니다.
- 측정 불가능한 성공 지표를 작성하지 않습니다.
- 기존 PRD.md가 있으면 덮어쓰기 전에 사용자 확인을 요청합니다.
- 구현 방법(How)이 아닌 요구사항(What)만 기술합니다.
